# Universal Overlay для Windows

Лёгкий оверлей поверх игр: FPS, время кадра с графиком, 1% / 0.1% low,
графики любых датчиков (загрузка, частоты, температуры GPU/CPU, память),
гибкая настройка внешнего вида и размера, автообновление с GitHub.

**[Скачать последнюю версию](https://github.com/wizzard111/universal-overlay-windows/releases/latest)** —
`universal-overlay-windows-x86_64.zip` — распакуйте и запустите `install.exe`.

Версии для других систем: [Linux](https://github.com/wizzard111/universal-overlay-linux) · [macOS](https://github.com/wizzard111/universal-overlay-macos).

Лицензия — [MIT](LICENSE). Что нового — [CHANGELOG](CHANGELOG.md).

## Установка, обновление, удаление

В архиве релиза наверху лежат только три программы, всё остальное — в `app\`:

| Файл | Что делает |
|---|---|
| `install.exe` | Устанавливает или переустанавливает. Один запрос UAC, окно — журнал установки |
| `update.exe` | Скачивает последний релиз с GitHub, проверяет SHA-256 и обновляет установленную программу. Старая версия удаляется целиком, настройки остаются |
| `uninstall.exe` | Удаляет программу, службу, ярлыки и автозапуск, про настройки и драйвер спросит |

В репозитории это `install.cmd`, `update.cmd`, `uninstall.cmd`: из исходников
они собирают программу (нужен [Rust](https://rustup.rs)) и запускают то же самое.
Удалить можно и из «Параметры → Приложения». Обновить — из настроек
(«Общие → Обновления»).

Что делает установщик — и только это:
* ставит подписанный драйвер [PawnIO](https://pawnio.eu) для температуры CPU
  (если его ещё нет — например, от FanControl или LibreHardwareMonitor);
* кладёт программу в `C:\Program Files\Universal Overlay`;
* регистрирует маленькую службу `uo-sensord` (см. ниже);
* добавляет пользователя в стандартную группу Windows «Пользователи журналов
  производительности» — она даёт обычной программе читать системные события
  вывода кадров (FPS). Действует после повторного входа в Windows;
* добавляет ярлыки в «Пуск», запись в «Приложения» и автозапуск.

Сам оверлей **работает без прав администратора**.

## Почему антивирус больше не должен ругаться

Оверлей устроен как программа, которой нечего скрывать:
* не повышает права и не просит «запустить от администратора»;
* устанавливается не скриптом PowerShell, а обычным установщиком с манифестом;
* у всех exe есть иконка, манифест и сведения о версии в свойствах файла;
* в игры ничего не внедряется: FPS берётся из системных событий ETW (тот же
  источник, что у Intel PresentMon), температура — через подписанный драйвер.

Полностью исключить ложные срабатывания эвристики у неподписанной программы
нельзя. Окончательное решение — подпись кода: сборка подписывает все exe, если
задать `WINDOWS_SIGN_PFX` и `WINDOWS_SIGN_PASSWORD` (в CI — секреты с теми же
именами). Бесплатный сертификат для открытых проектов выдаёт, например,
[SignPath Foundation](https://signpath.org). Если срабатывание всё же есть,
отправьте файл как ложное срабатывание: Bitdefender — bitdefender.com/submit,
Windows Defender — microsoft.com/wdsi/filesubmission.

## Температура CPU: служба uo-sensord

Драйвер PawnIO открывается только с полными правами, поэтому датчик читает не
оверлей, а служба `uo-sensord` (≈300 КБ). Она ждёт запроса в ядре и не
тратит процессор. Пока оверлей виден, раз в тик он ставит событие «нужен
замер». Служба одним вызовом `DeviceIoControl` читает регистр (AMD Zen 1–5:
`THM_TCON_CUR_TMP`, Intel: `IA32_PACKAGE_THERM_STATUS`), кладёт значение в
общую память и отвечает. Это микросекунды, и значение всегда свежее. Ни WMI,
ни .NET, ни LibreHardwareMonitor.

## Возможности

* **Время кадра и FPS** из ETW: DXGI (D3D10–12), D3D9, DxgKrnl (Vulkan,
  OpenGL и остальное). Внедрения в игру нет. График с подсветкой «плохих»
  кадров, пики не теряются: на пиксель рисуется самый медленный кадр.
* **1% / 0.1% low** — перцентиль или среднее худших кадров, окна настраиваются.
* **Графики любых датчиков** — сколько угодно, у каждого свои цвет, высота,
  окно истории, шкала.
* **Датчики:** GPU — загрузка, частоты, температуры (ядро, hotspot, память),
  потребление, напряжение, вентилятор, видеопамять (AMD ADL, NVIDIA NVML,
  остальные — счётчики Windows); CPU — загрузка, частота, температура; RAM.
* **Внешний вид:** раскладка столбцом или строкой, шрифт, размеры, цвета
  каждого датчика, фон, скругление, отступы, **размер оверлея** (25–400%),
  **прозрачность**, угол экрана и смещение, монитор с игрой или основной.
* **Настройки** — тёмная или светлая тема (или как в системе), 8 акцентных
  цветов, изменения применяются к оверлею сразу.

Горячая клавиша по умолчанию — **Ctrl+Alt+O**. `universal-overlay --toggle`
переключает оверлей (и запускает его, если он не запущен).

## Нагрузка

| Состояние | CPU | Память |
|---|---|---|
| Оверлей виден, считает FPS активной игры, график 30 Гц | ≈0,26% одного ядра | ~26 МБ |
| Оверлей виден, кадров нет | ≈0,08% одного ядра | ~26 МБ |
| Скрыт (только значок) | 0: нет таймеров, сбор кадров остановлен | ~2 МБ |
| Служба uo-sensord | 0, пока температура не запрошена | ~8 МБ |

Замер: Ryzen 5 5600X, Radeon RX 9060 XT, Windows 11.

Что делает его лёгким:
* опрашиваются только датчики, которые показаны или стоят на графике;
* между тиками датчиков перерисовывается только график, и в окно уходит только
  его прямоугольник (`UpdateLayeredWindowIndirect` с dirty-областью);
* low считаются выборкой за O(n), копируется только нужный хвост истории;
* графики датчиков перерисовываются раз в тик, рендер программный, без
  GPU-контекста; иконки — сжатые PNG в несколько КБ.

## Ограничения

Поверх игр в **эксклюзивном** полноэкранном режиме (старые DX9/DX11) оверлей
не виден. Нужен оконный режим без рамки или современный полноэкранный режим.

## Сборка

```
install.cmd                                   собрать и установить
powershell -File source\build\build.ps1       только собрать релиз → source\target\dist
```

Пуш тега `v*` запускает `.github/workflows/release.yml`: тесты, сборка,
публикация релиза с `SHA256SUMS.txt`.

## Структура

```
install.cmd  update.cmd  uninstall.cmd    установка, обновление, удаление
docs/                                     документация
source/
  crates/common     конфиг, горячие клавиши, шрифты, протокол службы датчиков
  crates/overlay    оверлей: ядро, рендер, кадры (ETW), датчики, трей
  crates/settings   приложение настроек
  crates/updater    апдейтер (curl и tar из Windows, проверка SHA-256)
  crates/sensord    служба температуры CPU (PawnIO)
  crates/setup      установщик / деинсталлятор
  resources/        иконка и общие ресурсы exe (манифест, версия)
  build/            сборка релиза
```
